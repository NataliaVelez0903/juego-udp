# Juego Multijugador UDP – libGDX

> Juego multijugador en tiempo real con servidor autoritativo usando UDP y libGDX.

---

## Descripción

Este proyecto implementa un juego multijugador (2–4 jugadores) donde los jugadores compiten llevando pelotas a sus zonas para sumar puntos antes de que se acabe el tiempo.

- Comunicación en tiempo real mediante UDP
- Servidor autoritativo
- Sistema de puntaje y temporizador
- Sala de espera y pantalla final

---

## Tecnologías

- Java
- libGDX
- UDP (Sockets)
- Gradle
